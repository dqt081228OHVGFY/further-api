01

开始前，准备这三项

Key 决定访问权限，模型标识决定请求发往哪里。

  1. key

    创建 API Key

    为应用创建独立 Key，保存完整密钥，并确认有效期与访问范围。

  2. tune

    选择可用模型

    复制完整模型标识，确认它支持示例使用的端点，并查看价格。

  3. account_balance_wallet

    确认账户额度

    确保账户有可用额度或适用的订阅权益，再开始请求。

03

04

没有得到预期结果？

先读响应中的错误消息，再按下面的方向检查。具体原因以响应为准。

401密钥或认证信息有误add

检查 Key 是否完整、是否已撤销，以及请求头格式。OpenAI 兼容接口使用 Authorization: Bearer YOUR_API_KEY；Messages 示例使用 x-api-key。

403额度不足或访问受到限制add

根据错误消息检查账户额度、Key 有效期、模型白名单、IP 限制和账户状态。不同限制可能返回相同状态码，请结合错误类型判断。

404接口路径或模型名称不匹配add

确认没有重复添加 /v1；从“模型与价格”复制完整模型标识，并核对模型支持的请求端点。

429请求过于频繁add

降低并发数与请求频率。如果响应带有 Retry-After，按提示等待；否则逐步延长重试间隔，避免连续重试。

5xx服务暂时未能完成请求add

稍后再试，并查看模型健康度与调用记录。若持续失败，保留发生时间、模型名称和错误消息，联系站点管理员协助排查。

lightbulb

准备接入现有客户端？ 将服务商设为 OpenAI 兼容接口，填写上方 Base URL、你的 API Key 和模型标识。若客户端会自动拼接 /v1，按它的说明填写站点根地址。
