01 / 为什么使用

模型、密钥与用量管理

01hub

统一接入

使用同一 API 地址调用可用模型。

02key

独立 API Key

为不同应用分别创建密钥，按需设置模型范围、有效期和访问限制。

03monitoring

调用可追踪

在控制台查看调用结果、Token 用量、耗时与实际消费。

02 / 接口示例

API 请求示例

选择 API 协议查看请求格式。

POST/v1/responses
curl https://your-domain.example/v1/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"YOUR_MODEL","input":"Hello, world."}'
将地址、Key 与模型名替换为你自己的配置。
