# RelayFor 原页面业务

词元贷、注册码保留原页面字段，使用 New API 用户、密码哈希、角色鉴权和余额，不启用演示响应。

## 词元贷

- 管理员保存 `PUT /api/admin/settings/token-loan` 后即可开放。未配置时关闭，亏损池初始为零。
- 仅正常状态的 `default` 用户组可借款；一个用户同时只有一笔未结清借款。借款记录、账户状态、New API 余额增加在一个事务内完成，提交后同步额度缓存。
- `POST /api/user/public-benefits/token-loan/check-in` 按 UTC+8 日期限制每天一次。按配置的最低签到额度减债，足额结清，第 4 次补足全部剩余；没有随机清账。
- 签到减少应还金额，不从用户钱包扣除或额外发放钱包余额。溢出额度只增加下一笔借款上限，借出下一笔时消耗该临时加成。同一天重复签到返回已经提交的签到记录。
- 亏损池按设置的上下限随机扣减，每用户每日最多设置次数；剩余不低于零。池未清零时停止新借款，已有借款仍能签到还款。

## 注册码

- 批量生成码使用 32 字节系统随机数。管理员可按批次、关键字、状态、用户组查看；清理未使用批次不会删除已使用凭证。
- 设置页的共享注册码与批量一次性码保持不同语义。共享码只保存密码哈希；一次性码只有在账户创建事务提交时核销，失败时恢复可用。
- 输入注册码通过摘要查询，避免共享码出现在数据库查询日志中。普通注册仍执行 New API 的开关、邮箱验证码、频控、密码验证和用户字段清洗。
- LinuxDO 沿用 New API OAuth state、身份验证和会话流程。`POST /api/oauth/state` 在 `provider=linuxdo`、`intent=login` 时接受最长 128 字符的 `registration_code`；内部 state 只保存凭证引用。新账户在现有创建事务内核销码并发放统一初始额度与 LinuxDO 额外额度；已有账户登录不再次消耗码。
- 所有用户组使用同一套注册开关、注册码要求和初始额度。注册码的 `user_group` 仅决定普通用户组；不再包含付费站专用开关、共享码或初始额度配置。
- `GET /api/relayfor/registration/config` 公开注册开关与是否需要码，不暴露共享码、哈希、初始额度或客户密钥。

配置和生成、删除操作要求超级管理员；管理员可以读取配置和批次。变更写入 New API 管理审计，审计不包含注册码明文。
