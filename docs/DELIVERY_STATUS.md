## 明确没有完成

1. **渠道及上游 Key 的独立配额、RPM、并发、Key 权重完整执行链。** 已有稳定 Key ID 和预算模型，但非默认配置会明确拒绝，不能当成已生效。
2. **非 1 倍率套餐的异步任务折扣完整生命周期。** 当前在提交上游前拒绝并退还预扣；普通钱包／无折扣套餐保留原行为，历史异步任务未迁移重算。
3. **原高级路由、别名、每模型独立渠道权重／优先级、部分会话和运行参数。** New API 自身对应的高级管理功能仍可用，但旧表单中不能等价执行的配置会明确报错。
4. **原公共多次、订阅型／展期型及带独立额度组的兑换码。** 普通额度兑换已有实现；这些高级类型尚未闭合。
5. **部分旧安全操作表单逐项接线。** 旧改密码、TOTP 策略、Key 轮换、旧安全审计等部分路径尚未映射。完整 New API 账户安全功能可由新增入口进入。
6. **所有新增页面的原生界面转换。** 首页、原控制台／后台与反测活使用原 DOM；其余部分新增能力仍作为组件页面嵌入原内容区。认证表单复用 New API 安全流程，使用原页面外框样式。
7. **预付卡完全独立的逐 Key 资金隔离。** 限时额度复用 New API 订阅资金源和到期逻辑，应使用订阅优先；没有实现与所有其他账户 Key 完全隔离的新资金系统。
8. **真实上游与支付回调、MySQL／PostgreSQL／Redis 实库全矩阵验证。** 本轮主要验证 SQLite、mock Redis 原子契约、真实本地管理 API；没有用户上游密钥可做真实模型转发与支付验收。
