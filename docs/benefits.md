# 订阅与福利

本页记录 `further-api` 的签到、节日套餐、词元贷和注册码业务规则。界面操作使用真实账户、权限和持久化数据。

## 签到与节日套餐

- 每日签到与节日奖励独立配置、记录和领取。节日奖励在活动窗口内按 UTC+8 日期计算，每位符合条件的用户每天至多领取一次，并受活动用户组、名额和预算约束。
- 活动配置保留日期、内容、规则、主题和 `subscription_plan_ids` 付费套餐关联。套餐价格、额度和有效期在「订阅与福利」中维护，开通时单独确认并支付。
- 每个节日专场提供独立的 `.ics` 日历导出。导出当前活动日期后，用户可以在自己的日历应用中安排提醒。
- 免费节日关注已撤下。旧 `PUT /api/user/activities/subscription` 在认证后返回 `410 Gone` 和 `HOLIDAY_FOLLOW_RETIRED`，不再读取或修改历史关注记录。活动响应不包含关注状态、开关或人数；历史表不被删除。

## 词元贷

- 超级管理员保存词元贷设置后开放该能力；未配置时关闭。
- 正常状态的 `default` 用户组可以借款，每位用户同时最多保留一笔未结清借款。借款记录、账户状态和余额在同一事务内变更。
- 每个 UTC+8 日期至多签到一次。签到按设定额度减少债务；第 4 次补足剩余金额。同日重复签到返回已提交记录。
- 签到不从钱包扣款，也不额外发放钱包余额。超出应还金额的部分仅增加下一笔借款上限。
- 亏损池不能低于零；池中仍有余额时停止新借款，已有借款仍可签到还款。

## 注册码

- 批量注册码使用系统随机数生成。共享码与一次性码是不同类型；共享码只存密码哈希，一次性码在账户创建事务提交时核销。
- 输入码通过摘要查询，避免明文进入数据库查询日志。普通注册仍受站点开关、邮箱验证、频控和密码规则约束。
- 通过 LinuxDO 创建新账户时，注册码跟随 OAuth 状态传递，并在账户创建事务中核销；已有账户登录不会再次消耗注册码。
- 管理配置、生成与删除要求超级管理员；管理员可以查看配置和批次。审计记录不包含注册码明文。

具体接口以当前服务端路由和 OpenAPI 定义为准。
